# FileWeave 原生界面约定

2026-11-01 用户批准原生界面重构。Android 采用 Kotlin / Jetpack Compose / Material 3，并通过互操作保留成熟 Views 文件浏览能力；Mac 采用 SwiftUI / AppKit 的原生工作界面。用户随后明确菜单栏左键即可直接使用，独立窗口作为可选入口。使用平台系统字体、语义颜色与原生交互。以下为设计约定，实际落地和验证范围以 VALIDATION.md 为准。

## 页面职责与语言

- Android 按文件、设备、传输组织主导航；文件浏览优先显示内容，传输历史不占据文件列表前方。保险库、共享目录仍应使用可识别的文件行。
- Mac 菜单栏左键直接打开可操作工作面板，文件、录音/转录、收件箱和设备功能可在面板内完成；独立窗口提供更大的可调整工作空间。容量趋势按需进入，避免与文件内容长期争夺空间。
- 主操作、次要操作、危险操作、文件内容分别有明确视觉语义；加载、空、离线、失败、成功不能共用一段无层级正文。
- 默认英文，提供简体中文选择并持久保存；文案集中资源化。文件名、目录路径、用户输入、剪贴板及转录原文不随界面语言翻译。
- 两端共享产品术语与状态含义，各自遵循平台布局、输入与无障碍规则。

## 图标语义

- 筛选入口统一使用漏斗图标，复用 `filter_icon_control_normal_24dp`；排序保留独立的排序图标，不再用相似的递减横线表示筛选。保留 24dp 尺寸、主题着色及文字／无障碍标签。

## 间距与排版

- 使用平台语义文字层级，不把标题、说明、文件元信息统一成相同字号。相关标题和说明紧凑成组，分组之间保留更明显的距离。
- Mac 面板状态区水平内边距 16pt、垂直 12pt，同组标题与说明间隔 4pt，主要分组间隔 12pt。列表拥有稳定可滚动的工作面积，状态区按内容测量，不预留空任务槽，不叠加额外安全区形成上下空带。系统弹出框的箭头和边框不算内容留白。
- Android 新页使用 Material 3 的标题栏、列表行、控件与文字层级；分组标题和说明采用统一的 24dp 页面边距。列表图标与正文按组件对齐，点击范围至少 48dp，不以减小触摸目标换取紧凑。
- 文件选择器将任务标题和路径分行；窄屏时次要工具归入菜单，不能让标题与路径互相覆盖。
- 内容行可为长文件名合理换行或省略，完整值仍通过对应详情可达；错误提示和操作标签应保留足够空间。中英文、150% 字体和窄窗口需分别检查，不能仅按中文短标签定宽。
- Mac 头部统一组织设备／连接、搜索与常用操作，按内容和实际宽度并排或收纳，不固定给搜索单独一行，也不把设备和活动硬分成等宽列。设备名与简短连接状态紧凑成组，完整详情按需可达；空闲状态不单独占一行。压缩头部应增加文件工作区，不能靠缩小文字或隐藏错误实现。
- 文件标题先获得可读宽度，再安排搜索等常用操作；筛选、排序和视图按可用宽度收到更多菜单，激活的条件仍须可识别。不要给路径固定预留一整组工具的宽度。
- 路径优先露出当前目录和邻近层级，重复祖先可收纳但仍能访问；导航返回和窗口变窄后也保持当前层级可见。文件名与自定义存储名称原样显示，系统主存储标签使用应用语言。
- Mac 文件行必须区分普通、悬停、选中和失焦选中；选中状态优先于悬停，键盘导航与操作目标保持一致。
- Mac 非根目录使用独立一行面包屑，祖先目录可直接点击，长路径优先保留当前位置并提供完整路径；根目录不保留空导航行。范围选择菜单与面包屑职责分开。
- 显示隐藏文件是持久保存的全局文件浏览偏好，默认关闭，不重置用户已保存的选择；它只控制显示，不改变文件内容、权限或直接路径访问。
- 菜单栏弹出框在显示前确定有界工作区尺寸，由系统负责锚点定位；不得靠打开后的多轮移动或抢焦点修正布局。验收必须观察首次可见后的连续帧，不能只检查静止截图。

## 菜单与分层操作

菜单审查清单、各入口的重组方案与验收规则见 [Android 菜单规范](MENU_GUIDELINES.md)。

- 页面、目录、单文件、多选菜单按作用对象组织；应用级入口归侧栏，显示/排序归视图入口。
- 短菜单保留单层；选项过多先按状态筛选和职责迁移，再按任务分组。
- 有二级内容的操作面板必须提供明确的标题返回，系统返回也先退一级；仅在根层返回时关闭面板。
- 返回保留文件/目录、选择状态及父层滚动位置；取消不得执行动作。不能依赖关闭并重新打开菜单来回到父层。
- 分层菜单使用生命周期绑定的操作面板；旋转或进入后台时安全关闭，不继续使用旧页面对象。XML 菜单资源仅作为动作与状态模型，不依赖系统子菜单提供返回。

## 空状态与未选择状态

- 使用 `file_empty_state.xml` 的共同结构：装饰图标、简短标题、次级操作提示。
- 在所属内容区域或预览栏内居中，不放在容器左上角，不模仿文件条目或普通正文。
- 图标不单独播报；标题说明当前状态，次级提示说明下一步。文字居中、限制行宽，使用主题的次级文字色。
- 文件夹为空、搜索无结果、预览未选择文件分别提供准确文案；加载和读取错误继续使用独立状态，不混称为空。
- 双栏各自处理自己的状态。右侧未选择文件时不显示残留图片、属性或打开按钮。

## 文件视图

列表列数依据文件区域实际宽度与字体缩放计算。触摸目标不因紧凑视图缩小到 48dp 以下。
图片预览保留比例并利用右栏宽度；长属性可滚动，文件名、路径可选择复制。

## 搜索日期

日期按设备时区的自然日解释，开始日和结束日都包含在范围内。
缺少真实创建时间时不得拿修改时间或目录项变更时间替代；创建日期筛选必须说明此限制。
