# 项目定位

立项日期：2026-10-20。名称：FileWeave。当前阶段：0.4.0 手机文件夹共享与录音监视开发；0.2.1 已预发布。

## 核心目标

以 Material Files 的基础体验为中心，让 Android 上的文件浏览、视频观看、敏感文件保护，以及与 Mac 互通形成连贯流程。

用户已确认使用 Material Files 为基础；保留成熟文件操作与数据能力。2026-11-01 用户批准重新组织原生界面：Android 使用 Compose / Material 3 的文件、设备、传输入口，允许复用成熟 Views；Mac 菜单栏左键即可看到连接、任务和最近收件／录音概况并直接浏览主要文件；录音、收件箱和设备详情按需进入，另提供可调整的独立主窗口。新功能应围绕文件任务形成连贯流程，避免多个互不相干的工具页。该方向的实际实施与验收进度见 ROADMAP.md 和 VALIDATION.md。

## 主要流程

1. 浏览手机或 Mac 共享目录，点击普通视频即可播放并记住进度。
2. 将文件导入保险库，验证密文写入后再由用户决定是否移除原始明文。
3. 解锁保险库后直接查看视频；锁定时关闭读取会话并停止播放。
4. 在文件管理器中选择文件，通过「发送到 Mac」发送至已配对的 Mac 程序。
5. 用户明确操作后发送剪贴板文本到已配对设备，接收内容可预览并复制。
6. 配对后默认共享手机可访问的主存储和录音，提供明确开关；Mac 菜单栏面板可直接浏览和操作文件，独立窗口为可选工作空间。录音、转录集中在同一入口，转录文本保存到两端；指定文件或目录可以另外生成局域网只读下载链接。
7. 普通启动优先查看最近新增的系统已索引文件，侧栏与内部存储同级；用户可以配置最近列表的目录白名单或排除规则。局域网只读分享默认开放已授权主存储，支持限定范围、无 App 浏览器下载、图片预览和用户主动分享的剪贴板文本快照。

## 第一版边界

界面默认英文，支持用户主动切换简体中文并持久保存。两端与浏览器分享页采用一致术语；文件名、剪贴板与转录等用户内容不自动翻译。

优先局域网、Android 本地文件和 Mac SMB 共享。跨互联网中继、云账户、多人协作、双向目录自动同步、剪贴板历史和自定义加密格式不进入第一版。文件夹共享是 Mac 主动拉取的浏览／手动操作，不是后台自动同步。

已采用标准 gocryptfs 格式，并实现 Swift 菜单栏 + Python HTTPS 服务作为 Mac 开发版配套程序（0.4.0 起合并原独立项目「荣耀录音监视器」的 Mac 面板，移除其 ADB 通道与无鉴权桥接）。功能和实际验证范围见 FEATURES.md 与 VALIDATION.md。

产品名称为 FileWeave，当前 applicationId 为 `org.fileweave.android`。公开托管于 https://github.com/techfanseric/fileweave；当前仅发布开发版，不代表名称或商标已完成法律核验。
