# 原生界面与双语重构验收

用户于 2026-11-01 批准 Android Compose / Material 3、Mac 原生主窗口与菜单栏快捷面板，以及默认英文和简体中文支持。本文件定义验收条件；不代表已通过。实际执行结果记录于 VALIDATION.md。

## 通用要求

- 文件、设备、传输/历史各有明确职责；文件内容使用文件行，不伪装为主操作按钮；重要内容不被完整日志推到页面底部。
- 主操作、次要操作和危险操作层级清楚；加载、空、离线、失败、完成状态可区分，按钮状态反映真实任务。
- 用户特别要求检查间距与排版：相关元素紧凑成组、分组间距清楚、标题/文件行/按钮对齐；不能用固定容器高度制造无意义的上下空白，也不能叠加安全区和内边距导致内容被挤压。中英文和状态变化后重新测量。
- 界面沿用平台系统字体与语义颜色。英文、简体中文、长文件名、浅深主题及窗口变化均可读可操作。
- 用户文件名、路径、剪贴板和转录原文保持原样；协议标识、凭据与授权范围不随界面语言改变。
- 不新增统计/崩溃上报，不恢复 Firebase；不修改密文格式或将界面锁定称为文件加密。

## Android

- 普通启动进入文件主流程，可进入设备和传输。返回文件保留原路径和可保留的浏览状态。
- ACTION_OPEN_DOCUMENT、ACTION_CREATE_DOCUMENT、ACTION_OPEN_DOCUMENT_TREE 等选择器只承担选择任务；外部打开、快捷方式和分享入口仍正常。
- 主导航/新增功能页实际使用 Compose / Material 3；复用的 Views 范围需准确记录，不能声称已将全应用改写为 Compose。
- 保险库锁定/解锁、导入/导出/备份、共享文件、剪贴板和设置入口仍可达，文件能力不丢失。
- 用户未选择语言时使用英文；在中文系统环境首次启动仍为英文；切换简体中文后页面更新，重启保持。旧版明确语言选择的迁移规则可解释且一致。
- 进度及其他触摸控件具有足够操作范围；字体放大、横竖屏、窄/宽窗口不遮挡主操作，返回和取消不执行动作。
- Android assembleDebug、testDebugUnitTest、lintDebug 的结果、测试数与错误/警告分别记录。

## Mac

- 可打开和重新打开可调整尺寸的主窗口；文件/录音与转录/传输或历史/设备内容可达；窗口关闭不会意外退出后台服务。
- 用户后续明确要求菜单栏左键点开即可使用：面板内直接浏览、搜索和操作文件，录音、收件箱与设备内容可达；打开独立窗口只作可选入口，不能成为使用功能的必经步骤。无关容量图表不常驻挤占文件区域。
- 后续效率要求：默认面板不再提供四个等权标签；无需切页即可知道手机连接、进行中／失败任务和最近录音／收件状态，主要文件直接可浏览。录音／收件箱通过紧凑概况链接进入，设备与管理入口按需展开，次级内容有清楚的返回文件入口；返回保留目录与选择。
- 工作面板宽高适应屏幕和内容区域，普通、任务中、长错误状态均无额外空槽或不可达动作；列表需要稳定可滚动的工作面积，不能用空白状态槽填充边缘。主窗口与面板同时存在时，任务状态一致且搜索路由到实际操作的界面。
- 主窗口使用系统窗口与导航，菜单、快捷键、选择/打开语义一致。旧有多选、下载、复制、转录、摘要、回收站和设置能力仍可达。
- 容量历史在设备详情按需查看；离线明确标明数据时间，不把历史采样当实时值。
- 全新偏好默认英文，简体中文切换可持久保存；菜单、配对、错误、工具提示、容量日期和大小格式与选择一致。
- Swift debug/release 构建及测试均记录；真实界面截图应来自当前实现，不能复用旧固定宽度截图充当新窗口证据。

## 浏览器分享

- 默认英文，可切简体中文；登录/访问码、目录列表、图片预览、复制、下载、空态与错误保持所选语言。
- 切换语言后 token、当前目录、访问码状态和权限范围不变；不将用户文本作为 HTML 执行。
- 桌面和手机宽度、浅深模式至少有代表性目视检查，长文件名和中文不溢出关键操作。
