# 阶段任务与剩余工作

## 已完成的 0.2 开发版

- [x] 独立应用标识、上游历史与许可、移除 Firebase。
- [x] 内置 Media3 播放器、本地／已有网络文件随机读取、进度记忆、字幕入口、音轨与倍速控件。
- [x] 标准 gocryptfs 文件内容加密、独立密码、文件名保护及自动锁定。
- [x] 库内视频按块解密播放、图片与小型文本内存预览。
- [x] 锁定后旧读取失效、密文篡改失败、导入失败不删除来源、重名保护。
- [x] 密文备份导出与恢复、主动明文导出。
- [x] Mac 菜单栏配套程序、二维码／链接配对、证书固定 HTTPS、文件互传与共享视频播放。
- [x] Android 前台主动发送／读取文本的界面与协议。
- [x] 构建、lint、备份 JVM 测试、服务端协议测试，以及核心真机回归。

实际验证范围及限制见 VALIDATION.md。
